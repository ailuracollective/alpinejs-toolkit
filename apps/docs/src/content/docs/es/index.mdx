  <h2 id="un-caon-una-forma">Un cañón, treinta y nueve paquetes</h2>

Cada paquete tiene la misma forma: un controlador agnóstico del framework maneja el
estado, y un plugin finito lo sincroniza a un store, un magic o una directiva de
Alpine.

```ts
import Alpine from "alpinejs";
import accordion from "@ailura/alpinejs-accordion";

Alpine.plugin(accordion());

Alpine.start();
```

Como la forma es compartida, la documentación también lo es. Todas las páginas
siguen el mismo orden — instalar, registrar, un ejemplo que funciona, la tabla de
la API — así que la primera que leas te enseña las otras treinta y ocho.

  <Aside type="tip" title="Hacia dónde seguir">
    [Primeros pasos](/es/guide/getting-started/) es el camino mecánico: instalar,
    registrar, llamar. [Arquitectura](/es/guide/architecture/) es el razonamiento
    detrás del snippet de arriba — el ciclo de vida del controlador, las guardas de
    registro y las reglas de SSR. O elige una capa arriba y empieza por ahí.
  </Aside>
</ContainerSection>
